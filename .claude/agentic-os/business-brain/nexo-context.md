# Nexo Card — Product Context

## Product
**Nexo Card** is a crypto-backed card product:
- **Mastercard** issued via DiPocket (EEA, UK, LATAM)
- **Visa** issued via Zenus (~82 global countries)
- Available across EEA, UK, LATAM, and select global markets
- Primary revenue driver: **transaction volume**
- Strategic direction: evolving toward using the card as an **acquisition tool** that is self-sustainable
