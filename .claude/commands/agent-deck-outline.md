# agent-deck-outline

MODE: Agent (file creation required)

INPUT:
- PRD, decision framework, or feature summary.
- Output from /agent-decision for recommendation and tradeoffs.

OUTPUT:
Slide-by-slide presentation outline (Context, Problem, Options, Tradeoffs, Recommendation, Risks, Decision required).

---

Generate a slide-by-slide presentation outline.

Optimize for executive decision-making.

Include:
- Context
- Problem framing
- Options
- Tradeoffs
- Recommendation
- Risks
- Decision required

Avoid filler slides.
Assume limited time.
