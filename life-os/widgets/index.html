Life OS — Notion widgets

Six self-contained pages, no build step and no external requests except Open-Meteo in the weather widget. Paste a URL into a Notion /embed block. All of them follow the Notion light/dark theme automatically; add ?theme=light or ?theme=dark to pin one.

clock.html

Current time with weekday and date.

?tz=Europe/SofiaIANA time zone. Default: browser zone.
?h24=1|024-hour clock. Default 1; 0 gives AM/PM.
?seconds=1Show seconds. Default off.
?label=SofiaOptional caption under the date.
?theme=light|darkPin the theme.

Example: clock.html?tz=Europe/Sofia&seconds=1&label=Sofia

pomodoro.html

Focus timer with short/long breaks, session counter (long break every 4th), a soft WebAudio beep on completion and four accent colours.

?work=25Focus minutes. Default 25.
?short=5Short-break minutes. Default 5.
?long=15Long-break minutes. Default 15.
?accent=blue|green|
purple|orange		Accent colour. A choice made in the widget is remembered in localStorage when the browser allows it.
?theme=light|darkPin the theme.

Example: pomodoro.html?work=50&short=10&long=25&accent=purple

progress.html

Day / week / month / year completion bars with time remaining. Ticks every minute.

?tz=Europe/SofiaIANA time zone. Default: browser zone.
?weekstart=mon|sunFirst day of the week. Default mon.
?show=day,week,
month,year		Which bars to render, in this order. Default: all four.
?theme=light|darkPin the theme.

Example: progress.html?tz=Europe/Sofia&show=week,year

weather.html

Current conditions from Open-Meteo (no API key). Falls back to a cached result, then to a "weather unavailable" card if the network is blocked.

?city=SofiaCity name, geocoded by Open-Meteo. Default Sofia.
?units=c|fCelsius (default) or Fahrenheit; f also switches wind to mph.
?theme=light|darkPin the theme.

Example: weather.html?city=Lisbon&units=c

quote.html

Quote card with 61 built-in quotes. Contested attributions are credited as "Unknown" rather than guessed.

?seed=daily|randomdaily (default) keeps one quote per calendar day; random picks a new one on every load. The button always randomises.
?theme=light|darkPin the theme.

Example: quote.html?seed=random

invest.html

Compound-interest projection with a live SVG chart. Monthly compounding, deposits at the end of each month.

?cur=€Currency symbol. Default €.
?start=1000Starting amount. Default 1000.
?monthly=200Monthly deposit. Default 200.
?years=10Horizon, 1–60. Default 10.
?rate=7Annual return %, −20–40. Default 7.
?theme=light|darkPin the theme.

Example: invest.html?start=5000&monthly=500&years=20&rate=6&cur=£

Embedding tip: Notion embeds are roughly 300–700 px wide. Every widget is built to read cleanly from 300 px up, on a transparent background.
